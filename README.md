# VarshaGyan (वर्षा ज्ञान)

VarshaGyan is a prototype developed for Smart India Hackathon (SIH) 2026 Problem Statement 26074:

**Downscaling of Weather Forecasts from Block Level to Panchayat Level for Agro-Meteorological Advisory Services.**

The prototype demonstrates a workflow that converts a shared block-level weather forecast into Panchayat-level weather estimates using local geographic factors and provides simplified advisories for farmers alongside monitoring and evaluation tools for Panchayat officials.

---

# Problem Statement

Weather forecasts are often available for larger administrative regions such as Blocks. However, weather conditions can vary across villages within the same Block due to differences in terrain and local conditions.

The objective of this project is to demonstrate how a shared Block forecast can be transformed into Panchayat-level estimates and presented in a form useful for local decision making.

# Prototype Downscaling Workflow

The current prototype demonstrates the following workflow:

```text
Shared Block Forecast
        ↓
Local Terrain Factors
        ↓
Terrain Adjustment
        ↓
Panchayat Estimate
        ↓
Farmer Advisory
```

Example:

```text
Block Forecast
6.2 mm

↓

Lasalgaon
Adjustment: 0%
Estimate: 6.2 mm

↓

Pimpalgaon Baswant
Adjustment: +23%
Estimate: 7.6 mm
```

These values are demonstration outputs generated by the prototype workflow.

# Current Data Sources

The prototype currently uses:

- Open-Meteo weather data where available
- Sample fallback data when weather services are unavailable
- Demonstration terrain factors bundled with the application

The prototype does not currently use authorized IMD forecast datasets.

---

# Current Prototype Boundaries

The current version is a demonstration prototype.

Important limitations:

- Panchayat estimates are demonstration outputs.
- The terrain-adjustment workflow is not currently validated using Panchayat rain-gauge observations.
- No verified forecast accuracy metrics are included.
- The system is not an operational forecasting service.
- Example observations may be used for demonstration purposes.
- Crop selections are stored locally in the browser.
- Observation data is retained within the prototype environment.

The project should not be used for operational agricultural decision-making.

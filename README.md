# VarshaGyan

VarshaGyan is an AI-assisted Panchayat-Level Weather Downscaling System developed for Smart India Hackathon (SIH) 2026.

The platform transforms broad block-level weather forecasts into Panchayat-level estimates using local terrain factors and provides simple agricultural advisories to farmers while offering a dedicated monitoring dashboard for Panchayat officials.

## Key Features

- Block-to-Panchayat weather downscaling
- Farmer-friendly Marathi interface
- Panchayat monitoring dashboard
- Voice-based community observations
- Crop-specific advisory workflow
- Validation framework for future IMD integration
- Accessible rural-first design

## Problem Statement

SIH 2026 - PS ID 26074

Downscaling of weather forecast from Block level to Panchayat level for agro-meteorological advisory services.
